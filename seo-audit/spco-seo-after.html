01 — Executive summary

The spam is gone, the crawl path is clean, and every page reads in order.

Re-checking the site before starting surfaced a problem the baseline export could not see: the server was still publishing a spam sitemap left by a 2022 hack, 13 XML files listing German product-spam URLs on the firm's domain. They are now removed, and robots.txt declares the real sitemap instead of asking crawlers to wait ten seconds between pages.

Heading levels no longer skip on any page, every rendered image carries a description, pages are served from cache, and the site answers on one address only. The noindex block recorded in the baseline crawl had already been lifted before this work began, so it is not counted here. Throughout, the design, content, URLs and functionality were left exactly as they were.

-- — Delivered and verified

What changed in this round

  • The 2022 spam sitemap is removed. /sitemap/ (13 files, about 24 MB) and the script folder /contactq/ that generated it now return 404. Both were archived privately first.
  • robots.txt declares the sitemap and the crawl delay is gone. The original was a physical hosting-panel file, backed up before replacement.
  • The XML sitemap lists only real pages. 5 URLs. The empty client-resource page is set to noindex, which removes it from the sitemap. No page was deleted.
  • Heading levels descend in order on every page. 36 tag changes across 4 pages and the footer. No wording was changed and each heading looks exactly as before.
  • Pages are cached. LiteSpeed Cache installed with page caching only; a repeat page load now takes 6–10 ms at the server.
  • Mobile loading is lighter. Phones and tablets get a smaller hero image, preloaded, and five Google Fonts requests became one.
  • Duplicate stylesheets stopped. Five copies of icon and menu files that a plugin loaded on top of Elementor's own.
  • Images, phone links, favicon and host corrected. 3 images now carry alt text, both phone links use tel:+17057370983, the site has a favicon, and www.spco.ca redirects to spco.ca.

08 — Heading structure

Every page now reads H1 → H2 → H3, with no skips.

At baseline every page skipped heading levels. Headings had been chosen for how large the text looked rather than what it meant, so the home page opened with an H5 and the footer added H3 and H6 labels to every page. Only the tags were corrected; no wording changed.
