spco.ca SEO baseline audit

This document records spco.ca exactly as it was found on 20 November 2026, before any SEO work. Every figure comes from three inputs: a Screaming Frog crawl export, an OPEN SEO site audit, and a PageSpeed Insights desktop run of the homepage. Where the data doesn't cover something, the report says so instead of estimating. A companion results report will re-measure every figure here after the work is done.

01 — Executive summary

The site is well built and completely hidden from search.

Every page the audit found tells search engines not to list it and not to follow its links. While that instruction is in place, spco.ca cannot appear in Google for anything, including the firm's own name. It is one setting, not a structural fault, and it is the first fix in the action plan.

Underneath, the site is in reasonable shape. All 56 crawled URLs load without errors, the homepage title and description are well written for "tax and accounting in Barrie", and desktop Best Practices and Accessibility score 100 and 95. The remaining issues are smaller: skipped heading levels, two missing descriptions, an unlinked resource page, an exposed author page, no canonical tag, and duplicate stylesheet files.

05 — Crawlability & indexability

Every page is closed to search engines.

Crawlability is whether search engines can reach a page. Indexability is whether they may store it and show it in results. A page must pass both to rank.

Critical · F-01 and F-02
noindex, nofollow on 7 of 7 pages

Each page contains <meta name="robots" content="noindex, nofollow">. On WordPress this is most often the Settings → Reading → "Discourage search engines from indexing this site" option left on after development; an SEO plugin can also set it. The X-Robots-Tag header is empty, so the fix is in WordPress, not the server.

08 — Heading structure

One H1 on the homepage; skipped levels on every page.

Headings are the outline of a page: one H1 for the main topic, H2s for sections, H3s inside them. Jumping from H2 to H4 makes that outline harder for search engines and screen readers to follow.

15 — SEO action plan

Four phases, starting with the block.

Phase 1 · week 1

Open the site to search engines

  • Take a full backup.
  • Remove noindex, nofollow sitewide (F-01, F-02).
  • Decide whether the author archive and intake checklist should be indexed (F-05).
  • Check robots.txt and the sitemap; set up Search Console and submit the sitemap (F-04).
  • Confirm canonical tags now appear (F-03), then re-crawl the whole site.
Phase 2 · weeks 2–3

On-page fixes

  • Review titles and descriptions on every page from the new crawl; write the 2 missing ones (F-07).
  • Fix heading levels in shared templates, then each page (F-06, F-14).
  • Link the intake checklist from Client Resources (F-08) and correct its URL base with a 301 (F-13).
  • Audit image alt text from the Images export.
Phase 3 · weeks 3–4

Performance

  • Remove duplicate stylesheet and icon files (F-09).
  • Convert and resize the two heavy PNGs (F-10).
  • Confirm page caching and re-measure response time (F-11).
  • Run PageSpeed on mobile and desktop for key pages (F-12); switch to en-CA if the client agrees (F-15).
Phase 4 · week 6 on

Measure against this baseline

  • Re-run both crawls and PageSpeed with the same settings and compare against section 16.
  • Check Search Console for pages indexed against pages submitted.
  • Judge ranking movement over 4–8 weeks, not sooner.
