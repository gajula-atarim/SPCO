01Executive Summary

The website is currently hidden from search engines.

All 7 pages found by the audit (100%) carry a noindex, nofollow instruction. This tells Google and other search engines not to list the page in search results and not to follow its links. While it is in place, spco.ca cannot rank for anything, including the firm's own name.

The good news is that this is one setting, not a structural problem. The rest of the data shows a site in reasonable shape:

  • All 56 URLs crawled returned a successful 200 OK response, with no broken links or server errors.
  • The homepage title (54 characters) and meta description (154 characters) are well written, within recommended lengths, and mention the service and location (Barrie, ON).
  • Desktop PageSpeed scores are strong for Best Practices (100) and Accessibility (95). Performance is 86.
  • The homepage has exactly one H1 heading and about 1,000 words of content.

Beyond the indexing block, we found smaller issues: skipped heading levels on every page, 2 pages without a meta description, a resource page that no other page links to, an author archive page that exposes a login-style username, no canonical tag on the homepage, and duplicate stylesheet files that slow the page down.

One important limit: because the homepage told the crawler not to follow links, Screaming Frog only analysed 1 HTML page (the homepage). Page-level details for the other 6 pages come from OPEN SEO only. A full re-crawl is needed after the indexing block is removed. Section 16 lists what that re-crawl must capture.

05Crawlability & Indexability

Crawlability is whether search engines can reach a page. Indexability is whether they are allowed to store it and show it in results. A page has to pass both to rank.

F-01

Every page is blocked from search results

Critical

Each page contains <meta name="robots" content="noindex, nofollow">. Search engines obey this. The pages will be dropped from, or never added to, Google's index.

Current statusnoindex, nofollow
Affected7 of 7 pages (100%)
SEO impactNo search visibility at all
ActionRemove the directive, then confirm on every page

On WordPress this is most often the Settings → Reading → "Discourage search engines from indexing this site" option, left on after development. It can also be set by an SEO plugin. The X-Robots-Tag header is empty, so the block is in the page HTML and not the server configuration.

F-02

Links are not followed, so pages cannot be discovered

Critical

The nofollow part tells crawlers not to follow any link on the page. This is why Screaming Frog stopped after the homepage: it found 5 unique internal links but did not follow them. Google would behave the same way.

Current statusCrawl stops at the homepage
Affected7 of 7 pages (100%)
SEO impactInner pages can't be discovered through links
ActionFixed by the same change as F-01; then re-crawl the full site

08Heading Structure

Headings (H1 to H6) work like the outline of a document. There should be one H1 (the page's main topic), with H2s for sections and H3s inside them. Skipping a level, such as going from H2 to H4, makes the outline harder for search engines and screen readers to follow.

15SEO Action Plan

Phase 1
Week 1

Open the site to search engines

  • Take a full backup.
  • Remove noindex, nofollow sitewide (F-01, F-02).
  • Decide whether the author archive and intake checklist should be indexed; set them accordingly (F-05).
  • Check robots.txt and the XML sitemap; set up Google Search Console and submit the sitemap (F-04).
  • Confirm canonical tags now appear (F-03).
  • Re-crawl the full site with Screaming Frog and re-run OPEN SEO.
Phase 2
Weeks 2–3

On-page fixes

  • Review titles and meta descriptions for all pages using the new crawl; write the 2 missing descriptions (F-07).
  • Fix heading levels in shared templates, then on each page (F-06, F-14).
  • Link the intake checklist from the Client Resources hub (F-08).
  • Correct the resource URL base with a 301 redirect (F-13).
  • Audit image alt text from the new Images export.
Phase 3
Weeks 3–4

Performance

  • Remove duplicate stylesheet and icon files (F-09).
  • Convert and resize the two heavy PNGs (F-10).
  • Confirm page caching and re-measure response time (F-11).
  • Run PageSpeed Insights on mobile and desktop for key pages (F-12).
  • Switch site language to en-CA if the client agrees (F-15).
Phase 4
Week 6 onward

Measure against this baseline

  • Re-run both crawls and PageSpeed with the same settings and compare against Section 16.
  • Check Search Console's indexing report for pages indexed vs. submitted.
  • Indexing typically takes days to weeks; ranking movement should be judged over 4–8 weeks, not sooner.
