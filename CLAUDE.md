# Client reports

Every client-facing report (SEO baseline audits, results reports, any other audit) uses the WHC
report style in `reports/whc-brand/`. Read `reports/whc-brand/README.md` before writing one: same
fonts, colours, WHC logo header and section layout, built with `reports/whc-brand/build.py` and
published as an HTML artifact. Do not invent a different visual design for a report.
